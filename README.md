### ❓ Do I need to pay a percentage of the exchange turnover?

### ❓ How is liquidity ensured at launch?

The script comes with a ready-made connector to **Bybit**. The order book synchronizes automatically, creating the appearance of a large, active exchange from the first minutes of operation.

### ❓ Do I get the source code?

**Yes.** We provide clean source code without obfuscation. No ties to our servers or third-party licenses — you are the sole and rightful owner of the software.

### ❓ Is KYC/AML included?
